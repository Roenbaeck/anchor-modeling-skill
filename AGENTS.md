# Anchor Modeling

This repository holds one agent skill, `skills/anchor-modeling/`, for Anchor Modeling (sixth-normal-form temporal data modeling) on any SQL database.

When a task is about Anchor Modeling, whether designing, reverse-engineering, generating DDL for, loading, querying or extending an Anchor model, read `skills/anchor-modeling/SKILL.md` first and follow it. It tells you which of the files in `skills/anchor-modeling/references/` to read at each step. Do not read the files in `skills/anchor-modeling/generators/` into the conversation: they are programs to run (`references/generator.md` says how), 0.2 to 1.1 MB each.
